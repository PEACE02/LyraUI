# LyraUI

一个基于 Unreal Engine 5.8 的 CommonUI 学习项目。

本项目从最小可运行闭环开始学习 CommonUI，并以 Lyra Starter Game 作为架构参考。学习过程、关键决定和当前进度都会保存在仓库中，方便后续会话继续接手。
